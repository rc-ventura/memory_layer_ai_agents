# Bibliographic Review — Memory in Generative AI Agents and Update Techniques (Sub-activity 1.1)

Prepared for: Plano de Trabalho, IPT Open / Inova Talentos (Instituto Itaú de Ciência, Tecnologia e Inovação). Project: "Mecanismo de atualização de memória para agentes de IA generativa com aprendizado por reforço aplicado a fluxos jurídicos." Deliverable Sub-1.1: bibliographic review on memory in generative AI agents (short/long-term, episodic vs. semantic) and update techniques.

## TL;DR

- The literature strongly supports a memory design that separates a short-term/working context from a persistent long-term store, and further separates raw experience (episodic) from distilled, reusable knowledge (semantic/procedural); the single most authoritative anchor is the peer-reviewed survey by Zhang et al. (ACM Transactions on Information Systems, 2025; arXiv:2404.13501), the first survey dedicated to agent memory.
- For a controlled, signal-driven update mechanism, the most directly relevant work is recent (2025-2026): Memory-R1 (reinforcement learning over ADD/UPDATE/DELETE/NOOP operations), DMF (deterministic survival-scoring that eliminates LLM calls from the memory loop), ReasoningBank and Memp (distilling experience into reusable reasoning/procedural memory), complemented by classic decay/forgetting (MemoryBank) and reflection (Reflexion, Generative Agents).
- "Hermes Agent" is a real, verifiable open-source framework from Nous Research (MIT license, official repo github.com/NousResearch/hermes-agent) with a documented closed learning loop, layered memory, and automatic session-to-skill conversion; "smolagents" is Hugging Face's minimalist code-agent library with a well-documented step-based memory object. Both are industry/engineering artifacts, not peer-reviewed papers, and the project's comparison of the two is legitimate and documentable.

## Key Findings

- A recognized "write–manage–read" (or formation–evolution–retrieval) memory lifecycle now organizes the field. Multiple 2024-2026 surveys converge on treating agent memory as an explicit lifecycle and on distinguishing short-term (context-window/working) from long-term (external, retrieved) memory.
- Cognitive-science categories (episodic vs. semantic, plus procedural) have been operationalized in LLM agents. Generative Agents (Park et al., UIST 2023) is the canonical example: a raw "memory stream" (episodic) plus a reflection process that synthesizes higher-level insights (semantic). Recent position papers argue episodic memory is the missing piece for long-term agents.
- Update/consolidation/forgetting is the fastest-moving sub-area and the most relevant to this project. Techniques range from human-inspired decay (MemoryBank/Ebbinghaus), self-reflection (Reflexion), skill libraries (Voyager), OS-style paging (MemGPT/Letta), agentic note-linking (A-Mem), production pipelines (Mem0), RL-learned memory operations (Memory-R1), reasoning/procedural distillation (ReasoningBank, Memp), and fully deterministic scoring (DMF).
- The Hermes Agent vs. smolagents comparison is well-founded. Hermes offers the "session history → reusable skills" learning loop the project describes; smolagents offers a transparent, inspectable step-memory model with full programmatic control but no native long-term learning loop.

## Details

### Theme 4 (highlighted first) — Survey / review papers on memory in LLM agents

**A Survey on the Memory Mechanism of Large Language Model-based Agents** — Zeyu Zhang, Xiaohe Bo, Chen Ma, Rui Li, Xu Chen, Quanyu Dai, Jieming Zhu, Zhenhua Dong, Ji-Rong Wen. 2024/2025. Venue: arXiv:2404.13501; published in ACM Transactions on Information Systems (DOI 10.1145/3748302). Link: https://arxiv.org/abs/2404.13501. Peer-reviewed (journal). Core contribution: the first survey dedicated specifically to memory in LLM-based agents; formally defines the memory module, motivates it from cognitive psychology / self-evolution / applications, and gives taxonomies of memory design (structure, format) and operations (reading, writing, reflection) plus evaluation methods. A companion repository is maintained at github.com/nuster1128/LLM_Agent_Memory_Survey. Relevance: the natural backbone citation and taxonomy source for the whole deliverable; its "narrow vs. broad" memory definitions and operation taxonomy map directly onto a controlled update mechanism for legal workflows.

**Memory in the Age of AI Agents** — Yuyang Hu, Shichun Liu, and a large multi-institution author group. Dec 2025. Venue: arXiv:2512.13564. Link: https://arxiv.org/abs/2512.13564. Preprint (not peer-reviewed). Core contribution: a very large, recent survey proposing a three-axis taxonomy — Forms (token-level, parametric, latent), Functions (factual, experiential, working), and Dynamics (formation, evolution, retrieval) — and explicitly distinguishing agent memory from RAG and context engineering; compiles benchmarks and open-source frameworks. A companion paper list is maintained at github.com/Shichun-Liu/Agent-Memory-Paper-List. Relevance: the most current map of the field; its "Dynamics → evolution (consolidation & forgetting)" axis is exactly the sub-topic of the project, and it lists RL-integration and trustworthiness as frontiers.

**From Storage to Experience: A Survey on the Evolution of LLM Agent Memory Mechanisms** — Feishu Luo et al. 2026. Venue: arXiv:2605.06716. Link: https://arxiv.org/abs/2605.06716. Preprint. Core contribution: proposes an evolutionary three-stage framework — Storage (trajectory preservation), Reflection (trajectory refinement), Experience (trajectory abstraction) — unifying the OS-engineering and cognitive-science views that the authors note have kept the field fragmented. Relevance: the Storage→Reflection→Experience progression is a clean narrative for justifying converting session history into reusable rules.

**Rethinking Memory Mechanisms of Foundation Agents in the Second Half: A Survey** — 2026. Venue: arXiv:2602.06052. Link: https://arxiv.org/abs/2602.06052. Preprint. Core contribution: systematic curation of 218 key papers published between 2023 Q1 and 2025 Q4, with a taxonomy of memory in foundation agents; documents an exponential surge of the sub-field peaking in 2025 Q4. Relevance: useful for demonstrating that the deliverable covers the state of the art through late 2025.

Living-bibliography companions (not papers, useful for tracking): TsinghuaC3I/Awesome-Memory-for-Agents and Shichun-Liu/Agent-Memory-Paper-List on GitHub.

### Theme 1 — Memory architectures: short-term (working/context) vs. long-term (persistent/retrieved)

**Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks** — Patrick Lewis, Ethan Perez, Aleksandra Piktus, Fabio Petroni, Vladimir Karpukhin, Naman Goyal, Heinrich Küttler, Mike Lewis, Wen-tau Yih, Tim Rocktäschel, Sebastian Riedel, Douwe Kiela. 2020. Venue: NeurIPS 2020 (arXiv:2005.11401). Link: https://arxiv.org/abs/2005.11401. Peer-reviewed. Core contribution: introduces RAG, combining a parametric LLM with a non-parametric retrieval store (Wikipedia via dense retrieval) to ground generation and reduce hallucination. Relevance: the foundational "external memory as retrieval" pattern; for legal agents, statutes/case law form an authoritative non-parametric memory that can be updated far more cheaply than retraining. (The Harvard Journal of Law & Technology digest on RAG for legal work explicitly frames RAG's vector database as "non-parametric memory" for law — a useful practitioner motivation, non-academic.)

**MemGPT: Towards LLMs as Operating Systems** — Charles Packer, Sarah Wooders, Kevin Lin, Vivian Fang, Shishir G. Patil, Ion Stoica, Joseph E. Gonzalez. 2023. Venue: arXiv:2310.08560 (now the Letta framework). Link: https://arxiv.org/abs/2310.08560. Preprint (widely cited). Core contribution: virtual context management inspired by OS memory hierarchies — tiered "main context / recall / archival" storage with function-call-driven paging and interrupts, letting the LLM manage its own memory across the context boundary. Relevance: the canonical short-term/long-term tiering pattern; the function-call paging model is a concrete template for a controlled write path. Caveat noted in later work: MemGPT provides no principled forgetting, confidence estimation, or offline consolidation — its compression is append-then-summarize (recursive summarization), not homeostatic.

**Neural Turing Machines** (Alex Graves, Greg Wayne, Ivo Danihelka, 2014, arXiv:1410.5401) and **Hybrid computing using a neural network with dynamic external memory / Differentiable Neural Computer** (Graves et al., Nature, 2016). Peer-reviewed (Nature) / foundational preprint. Core contribution: memory-augmented neural networks (MANNs) with a neural controller and a differentiable external memory matrix accessed via attention-based read/write heads. Relevance: the historical root of "external memory + controller," still consistently cited as the origin of the external-memory idea; included as genuinely foundational, though not directly used in modern prompt-based LLM agents.

**Augmenting Language Models with Long-Term Memory** (LongMem) — Weizhi Wang, Li Dong, Hao Cheng, Xiaodong Liu, Xifeng Yan, Jianfeng Gao, Furu Wei. 2023. Venue: NeurIPS 2023. Peer-reviewed. Core contribution: a decoupled long-term memory module that lets an LLM cache and retrieve past context beyond the window. Relevance: foundational for the "persistent retrieved memory" pattern distinct from the working context.

### Theme 2 — Episodic vs. semantic memory in AI agents

**Generative Agents: Interactive Simulacra of Human Behavior** — Joon Sung Park, Joseph C. O'Brien, Carrie J. Cai, Meredith Ringel Morris, Percy Liang, Michael S. Bernstein. 2023. Venue: UIST 2023 (arXiv:2304.03442, DOI 10.1145/3586183.3606763). Link: https://arxiv.org/abs/2304.03442. Peer-reviewed. Core contribution: introduces the "memory stream" (a chronological episodic log of observations) retrieved by a weighted combination of recency, importance, and relevance, plus a reflection mechanism that periodically synthesizes memories into higher-level insights (semantic memory). Ablations show memory, reflection, and planning are each critical to believable behavior. Relevance: the canonical operationalization of episodic vs. semantic for LLM agents; the recency/importance/relevance scoring is a direct model for a signal-driven retrieval/update policy in a legal agent.

**Position: Episodic Memory is the Missing Piece for Long-Term LLM Agents** — Mathis Pink, Qinyuan Wu, Vy Ai Vo, Javier Turek, Jianing Mu, Alexander Huth, Mariya Toneva. 2025. Venue: arXiv:2502.06975. Link: https://arxiv.org/abs/2502.06975. Preprint (position paper). Core contribution: argues episodic memory should be a first-class design target and defines five properties — long-term storage, explicit reasoning, single-shot learning, instance-specific memories, and contextual memories (who/when/where/why). Relevance: a principled checklist for what a legal agent's episodic case-log store must support (e.g., binding facts to matter/client/date/outcome).

**Episodic Memory in AI Agents Poses Risks That Should Be Studied and Mitigated** — 2025. Venue: arXiv:2501.11739. Link: https://arxiv.org/abs/2501.11739. Preprint. Core contribution: analyzes safety/privacy risks of accumulating episodic memory in agents. Relevance: directly relevant to legal confidentiality/privilege — motivates why memory updates must be controlled, auditable, and forgettable.

**Learning from Supervision with Semantic and Episodic Memory: A Reflective Approach to Agent Adaptation** — 2025. Venue: arXiv:2510.19897. Link: https://arxiv.org/abs/2510.19897. Preprint. Core contribution: separates task-level insights (semantic memory) from context-specific information (episodic memory) and studies eager vs. lazy generalization strategies. Relevance: empirical support for keeping raw logs separate from distilled rules — the core of the project's proposed design.

### Theme 3 — Update, consolidation, editing, and forgetting techniques

**Reflexion: Language Agents with Verbal Reinforcement Learning** — Noah Shinn, Federico Cassano, Edward Berman, Ashwin Gopinath, Karthik Narasimhan, Shunyu Yao. 2023. Venue: NeurIPS 2023 (arXiv:2303.11366). Link: https://arxiv.org/abs/2303.11366. Peer-reviewed. Core contribution: reinforces agents through linguistic feedback rather than weight updates — the agent verbally reflects on task feedback signals and stores self-reflections in an episodic memory buffer to improve subsequent trials. Per the abstract, "Reflexion achieves a 91% pass@1 accuracy on the HumanEval coding benchmark, surpassing the previous state-of-the-art GPT-4 that achieves 80%." Relevance: the seminal "signal → reflection → memory update" loop without fine-tuning; the "feedback signal" framing maps directly to the project's "signal-driven" update requirement (e.g., a lost case, a corrected clause, a rejected filing).

**ExpeL: LLM Agents Are Experiential Learners** — Andrew Zhao, Daniel Huang, Quentin Xu, Matthieu Lin, Yong-Jin Liu, Gao Huang. 2023/2024. Venue: arXiv:2308.10144; AAAI 2024, pp. 19632–19642. Link: https://arxiv.org/abs/2308.10144. Peer-reviewed. Core contribution: an agent that autonomously gathers experiences across a collection of training tasks and extracts natural-language insights from them — without any parametric updates — by explicitly comparing successful and failed trajectories. Official code: github.com/LeapLabTHU/ExpeL. Relevance: the corpus's clearest example of turning raw win/loss trial outcomes directly into reusable natural-language insight, feeding the operation vocabulary the project needs for Sub 3.2.

**Retroformer: Retrospective Large Language Agents with Policy Gradient Optimization** — Weiran Yao, Shelby Heinecke, Juan Carlos Niebles, Zhiwei Liu, Yihao Feng, Le Xue, Rithesh Murthy, Zeyuan Chen, Jianguo Zhang, Devansh Arpit, Ran Xu, Phil Mui, Huan Wang, Caiming Xiong, Silvio Savarese (Salesforce AI Research). 2023/2024. Venue: arXiv:2308.02151; ICLR 2024. Link: https://arxiv.org/abs/2308.02151. Peer-reviewed. Core contribution: a separate retrospective model that tunes the language agent's prompts from environment feedback via policy gradient — genuine gradient-based reinforcement learning, learning across arbitrary reward signals from multiple environments and tasks, as opposed to verbal self-critique. Relevance: the corpus's only case of literal RL (as distinct from Reflexion's verbal reinforcement learning), and the direct anchor for Sub 1.3's RL survey.

**SCM: Enhancing Large Language Model with Self-Controlled Memory Framework** — Bing Wang, Xinnian Liang, Jian Yang, Hui Huang. 2023/2025. Venue: arXiv:2304.13343; DASFAA 2025. Link: https://arxiv.org/abs/2304.13343. Peer-reviewed. Core contribution: three components — an LLM-based agent, a memory stream, and a dedicated memory controller that decides when and how to update and retrieve from the stream; processes ultra-long inputs without fine-tuning, in a plug-and-play design over any instruction-following LLM. Official code: github.com/wbbeyourself/SCM4LLMs. Relevance: the corpus's most direct architectural match for the project's own framing — a dedicated, controllable memory-update component maps almost literally onto the "controlado" in the project's title.

**Voyager: An Open-Ended Embodied Agent with Large Language Models** — Guanzhi Wang, Yuqi Xie, Yunfan Jiang, Ajay Mandlekar, Chaowei Xiao, Yuke Zhu, Linxi Fan, Anima Anandkumar. 2023. Venue: arXiv:2305.16291, later Transactions on Machine Learning Research (TMLR) 2024. Link: https://arxiv.org/abs/2305.16291. Peer-reviewed (TMLR). Core contribution: an ever-growing skill library of executable code stored in a vector DB and retrieved by similarity, with self-verification before a skill is committed; skills are compositional and mitigate catastrophic forgetting. Per the abstract, Voyager "obtains 3.3x more unique items, travels 2.3x longer distances, and unlocks key tech tree milestones up to 15.3x faster than prior SOTA," and is the only method to unlock the diamond tier. Relevance: the archetype for "distill experience into reusable, retrievable skills with a verification gate" — directly analogous to converting session history into vetted legal procedures.

**MemoryBank: Enhancing Large Language Models with Long-Term Memory** — Wanjun Zhong, Lianghong Guo, Qiqi Gao, Yanlin Wang, Yan Wang. 2023/2024. Venue: arXiv:2305.10250; published AAAI 2024 (DOI 10.1609/aaai.v38i17.29946). Link: https://arxiv.org/abs/2305.10250. Peer-reviewed. Core contribution: hierarchical event-based memory with an updating mechanism inspired by the Ebbinghaus forgetting curve — memories are reinforced on recall and decay over time; retrieval via FAISS dense representations; demonstrated in the SiliconFriend companion chatbot. Relevance: the canonical forgetting/decay mechanism; a legal agent needs controlled decay so superseded law fades while durable doctrine is reinforced.

**A-MEM: Agentic Memory for LLM Agents** — Wujiang Xu, Zujie Liang, Kai Mei, Hang Gao, Juntao Tan, Yongfeng Zhang. 2025. Venue: arXiv:2502.12110; NeurIPS 2025. Link: https://arxiv.org/abs/2502.12110. Peer-reviewed. Core contribution: Zettelkasten-inspired memory where each memory is a structured note (keywords, context, tags) dynamically linked to others; a "memory evolution" step lets existing notes be retroactively refined/strengthened. The system reports "up to a six-fold improvement in ROUGE-L for multi-hop tasks with non-GPT models" while reducing "token usage per memory operation by 85-93% compared to baselines" (evaluated on LoCoMo vs. MemGPT/MemoryBank/ReadAgent). Relevance: a concrete model for evolving/editing an interconnected knowledge net rather than an append-only log.

**Mem0: Building Production-Ready AI Agents with Scalable Long-Term Memory** — Prateek Chhikara, Dev Khant, Saket Aryan, Taranjeet Singh, Deshraj Yadav. 2025. Venue: arXiv:2504.19413; ECAI 2025. Link: https://arxiv.org/abs/2504.19413. Peer-reviewed. Core contribution: a production memory layer with an extract→consolidate→retrieve pipeline (plus a graph variant, Mem0g) that dynamically extracts salient facts and resolves conflicts. On the LoCoMo benchmark it reports "a 91% lower p95 latency and saves more than 90% token cost" versus full-context, and "26% relative improvements in the LLM-as-a-Judge metric over OpenAI" (66.9% vs. 52.9%; p95 latency 1.44s vs. 17.12s). Relevance: a deployable reference architecture; note the documented critique that Mem0's update/delete decisions are delegated to the LLM without principled decay or scheduling — precisely the gap the project's controlled mechanism can address.

**Memory-R1: Enhancing Large Language Model Agents to Manage and Utilize Memories via Reinforcement Learning** — Sikuan Yan, Xiufeng Yang, Zuchao Huang, Ercong Nie, Zifeng Ding, Zonggen Li, Xiaowen Ma, and colleagues (LMU Munich / Munich Center for Machine Learning; senior authors Hinrich Schütze, Volker Tresp, Yunpu Ma). 2025. Venue: arXiv:2508.19828. Link: https://arxiv.org/abs/2508.19828. Preprint. Core contribution: an RL framework with a Memory Manager that learns structured operations — ADD, UPDATE, DELETE, NOOP — after each dialogue turn, and an Answer Agent that filters retrieved entries before reasoning; both fine-tuned with PPO/GRPO using only QA-correctness as reward. Per the abstract, "with only 152 training QA pairs, Memory-R1 outperforms strong baselines and generalizes across diverse question types, three benchmarks (LoCoMo, MSC, LongMemEval), and multiple model scales (3B-14B)." Relevance: the closest analogue to the project's core goal — learning when and how to update memory via a reward/RL signal rather than heuristics; the discrete ADD/UPDATE/DELETE/NOOP action set is a ready-made controlled-update vocabulary. (Minor caveat: the exact author count/order varies slightly across secondary citation lists; lead and senior authors are consistent.)

**DMF: A Deterministic Memory Framework for Conversational AI Agents** — Matteo Stabile and Enrico Zimuel (Roma Tre University). 2026. Venue: arXiv:2606.03463. Link: https://arxiv.org/abs/2606.03463. Preprint. Core contribution: replaces LLM-based memory summarization with a fully deterministic pipeline — each interaction receives a "Survival Score Ω" computed from content signals, conversational cues, and structured provenance combined via a logistic projection, plus an interaction-count decay law; no LLM calls in the memory-management loop. Per the abstract, "DMF achieves comparable accuracy while using zero tokens to prepare the memory context and 5x to 242x fewer tokens over the entire conversation" (vs. Mem0, on LoCoMo/LongMemEval), concluding "it is possible to eliminate LLM calls from the memory-management loop... enabling deterministic memory systems." Relevance: the strongest example of a deterministic, signal-driven, auditable update rule — highly attractive for legal settings where every memory change must be explainable and reproducible.

**ReasoningBank: Scaling Agent Self-Evolving with Reasoning Memory** — Siru Ouyang, Jun Yan, I-Hung Hsu, Yanfei Chen, Ke Jiang, Zifeng Wang, and 11 more (Google Research; 17 authors total). 2025. Venue: arXiv:2509.25140; accepted to ICLR 2026. Link: https://arxiv.org/abs/2509.25140. Peer-reviewed (ICLR 2026). Core contribution: distills generalizable reasoning strategies (structured as Title/Description/Content items) from the agent's own successful and failed experiences in a retrieve→construct→consolidate loop, plus Memory-aware Test-Time Scaling (MaTTS) that generates diverse/contrastive trajectories to improve memory quality. The abstract states it "consistently outperforms existing memory mechanisms that store raw trajectories or only successful task routines" across web-browsing and software-engineering benchmarks (directional; no single headline percentage in the abstract). Relevance: shows how to learn from both wins and losses — for legal work, losing arguments are as instructive as winning ones.

**Memp: Exploring Agent Procedural Memory** — Runnan Fang, Yuan Liang, Xiaobin Wang, Jialong Wu, Shuofei Qiao, Pengjun Xie, Fei Huang, Huajun Chen, Ningyu Zhang (Zhejiang University + Alibaba Group). 2025. Venue: arXiv:2508.06433; ACL 2026 Findings. Link: https://arxiv.org/abs/2508.06433. Peer-reviewed (ACL Findings). Core contribution: treats procedural memory as a learnable, updatable, lifelong object; distills trajectories into both fine-grained step-by-step instructions and higher-level script-like abstractions, and systematically studies Build/Retrieval/Update strategies with a dynamic regimen that corrects and deprecates memory. On TravelPlanner and ALFWorld, "as the memory repository is refined, agents achieve steadily higher success rates and greater efficiency," and procedural memory built from a stronger model "migrated to a weaker model can also yield substantial performance gains" (directional; no single headline percentage in the abstract). Relevance: the most direct academic treatment of "convert session history into reusable procedures," including explicit deprecation — exactly the project's mechanism.

### Framework comparison (Theme 3, applied) — Hermes Agent vs. smolagents

**Hermes Agent** — Nous Research. Open-source, MIT license. Official repo: https://github.com/NousResearch/hermes-agent; docs at hermes-agent.nousresearch.com. Industry/engineering artifact (not peer-reviewed). Verification: confirmed a real, official Nous Research project via the organization's own GitHub repository and documentation site (README describes it as "The self-improving AI agent built by Nous Research... the only agent with a built-in learning loop"). Documented design: a closed learning loop that (a) tracks multi-step tasks in an episodic layer (every tool call, decision branch, correction), (b) after several successful completions of a task pattern distills a reusable skill as a `SKILL.md` file (compatible with the agentskills.io open standard) using progressive disclosure so idle skills cost near-zero tokens, and (c) can patch its own skills mid-session via a skill_manage tool. Layered memory: MEMORY.md (facts), USER.md (user model), plus the skills library; cross-session recall via SQLite FTS5 full-text search with LLM summarization; optional deeper self-improvement through the Atropos RL pipeline (RLHF/DPO, ShareGPT trajectory export). Relevance: Hermes is essentially a production embodiment of the project's thesis (session history → reusable rules/skills with a native learning loop); its skill-file transparency and community trust-tiering (builtin > official > community) are attractive for auditable legal use. Caveats: claims come from vendor docs/blogs, not independent peer review; numerous third-party writeups (Medium/DEV/Substack) are secondary. A separate fan site (hermes-agent.ai) states it is "not affiliated with Nous Research" — prefer the official repo/docs (hermes-agent.nousresearch.com) when citing, and treat GitHub star counts / version numbers as volatile.

**smolagents** — Hugging Face. Open-source (Apache-2.0). Docs: https://huggingface.co/docs/smolagents. Industry/engineering artifact (not peer-reviewed). Design: a minimalist library — per the official README, "the logic for agents fits in ~1,000 lines of code... We kept abstractions to their minimal shape above raw code!" — whose flagship CodeAgent writes and executes Python at each step, while a ToolCallingAgent uses JSON tool calls; the project reports that code-writing agents cut "steps and LLM calls by about 30%" versus standard JSON tool-calling. Memory model: an explicit agent.memory object holding an ordered list of steps (TaskStep, ActionStep, PlanningStep); agent.write_memory_to_messages() serializes logs into chat messages each step, and developers can read, replay, or directly modify agent.memory.steps (including injecting another agent's memory). Secure execution via a restricted local interpreter or E2B/Docker/Blaxel sandboxes. Relevance: smolagents provides transparent, inspectable short-term/working memory and full programmatic control over the step log, but has no native long-term learning loop or automatic session→skill consolidation — the contrast that motivates the project. It is an ideal substrate on which to build a controlled update mechanism (the memory is fully exposed), whereas Hermes ships an opinionated loop out of the box.

### Legal / juridical application context

**LLM Agents in Law: Taxonomy, Applications, and Challenges** — 2026. Venue: arXiv:2601.06216; ACL 2026 (long paper). Link: https://arxiv.org/abs/2601.06216. Peer-reviewed. Core contribution: a taxonomy of legal LLM agents across retrieval, judgment prediction, courtroom/dispute simulation, compliance, advisory, and contracts; identifies hallucination, outdated information, and verifiability as the key deployment barriers, with planning/memory/tool-use as mitigations. Relevance: frames why controlled memory (freshness, verifiability) is essential in law.

**LAW: Legal Agentic Workflows for Custody and Fund Services Contracts** — Watson, Cho, Srishankar, et al. (JPMorgan Chase AI Research). 2024. Venue: arXiv:2412.11063. Link: https://arxiv.org/abs/2412.11063. Preprint (industry research). Core contribution: a modular, reusable agentic workflow with legal-domain-specific tools and text agents, orchestrating plans that outperform a baseline on retrieval and analytical contract queries; applicable to both open and closed models without fine-tuning. Relevance: concrete evidence that reusable, modifiable agent components work on real legal contract tasks.

**Large Language Models in Legal Systems: A Survey** — 2025. Venue: Humanities and Social Sciences Communications (Nature Portfolio), article s41599-025-05924-3. Peer-reviewed. Core contribution: surveys LLMs across legal drafting, research, reasoning, education, and client interaction, and stresses that RAG pipelines and continual learning are needed to keep models current with evolving case law and regulations. Relevance: supports RAG-as-memory plus controlled update for legal freshness, and lists hallucination-mitigation (rule-grounded generation, fact verification) as an open problem the project can target.

## Recommendations

- Anchor the deliverable on the peer-reviewed survey (Zhang et al., ACM TOIS 2025) and its taxonomy, then layer the 2025-2026 surveys (Memory in the Age of AI Agents; From Storage to Experience; Rethinking Memory... Second Half) for currency. Use these to define short/long-term and episodic/semantic/procedural precisely, and to justify the "formation → evolution → retrieval" lifecycle framing.
- Adopt a two-tier design and cite the matching primitives: an episodic case-log store (Generative Agents memory stream; the Position paper's five properties) plus a distilled semantic/procedural rule store (Voyager skill library; Memp; ReasoningBank). This separation is empirically supported (Learning from Supervision with Semantic and Episodic Memory).
- For the update mechanism, prototype and benchmark three concrete strategies and select per criticality: (a) deterministic signal scoring (DMF) where auditability/reproducibility is paramount — the natural default for regulated legal changes; (b) RL-learned ADD/UPDATE/DELETE/NOOP (Memory-R1) where you have reward signals such as case outcomes or attorney corrections — the closest fit to the project's "aprendizado por reforço" mandate; (c) decay/reinforcement (MemoryBank) for graceful obsolescence of superseded statutes/precedent. Use Reflexion's verbal-feedback loop as the low-cost, no-fine-tuning baseline.
- Frame the framework comparison honestly and use it to set the build target: Hermes Agent = a ready-made closed learning loop (session→skill) that is a strong reference design but vendor-documented; smolagents = transparent, controllable step-memory with no native long-term loop. Recommend building the controlled update mechanism on smolagents (full programmatic memory access) while adopting Hermes' skill-file format, progressive disclosure, and trust-tiering as design patterns.
- Bake in legal-specific guardrails from the start: freshness/verifiability (LLM Agents in Law; Legal LLM survey) and the privacy/privilege risks of episodic memory (arXiv:2501.11739). Thresholds that should change the plan: if memory-driven answers exceed an acceptable hallucination or staleness rate on a held-out legal QA set, shift weight toward deterministic scoring (DMF-style) and require human-in-the-loop confirmation before any UPDATE/DELETE is committed to the long-term store; conversely, expand RL-driven autonomy only once outcome-linked reward signals are shown to correlate with expert-rated answer quality.
