# From Storage to Experience: A Survey on the Evolution of LLM Agent Memory Mechanisms

- **Authors:** Feishu Luo et al.
- **Year:** 2026
- **Venue:** arXiv:2605.06716
- **Link:** https://arxiv.org/abs/2605.06716
- **Tags:** survey, storage, reflection, experience, evolutionary-framework

## Core contribution

Proposes an evolutionary three-stage framework — Storage (trajectory preservation), Reflection (trajectory refinement), Experience (trajectory abstraction) — unifying the OS-engineering and cognitive-science views that had kept the field fragmented.

## Relevance to the project

The Storage→Reflection→Experience progression is a clean narrative for justifying converting session history into reusable rules.
