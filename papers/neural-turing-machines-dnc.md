# Neural Turing Machines / Hybrid Computing Using a Neural Network with Dynamic External Memory (Differentiable Neural Computer)

- **Authors:** Alex Graves, Greg Wayne, Ivo Danihelka (NTM, 2014); Graves et al. (DNC, Nature, 2016)
- **Year:** 2014 / 2016
- **Venue:** arXiv:1410.5401 (NTM); Nature (DNC, 2016)
- **Link:** https://arxiv.org/abs/1410.5401
- **Tags:** mann, differentiable-memory, historical-root

## Core contribution

Memory-augmented neural networks (MANNs) with a neural controller and a differentiable external memory matrix accessed via attention-based read/write heads.

## Relevance to the project

The historical root of "external memory + controller," still consistently cited as the origin of the external-memory idea; included as genuinely foundational, though not directly used in modern prompt-based LLM agents.
