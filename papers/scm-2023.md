# SCM: Enhancing Large Language Model with Self-Controlled Memory Framework

- **Authors:** Bing Wang, Xinnian Liang, Jian Yang, Hui Huang
- **Year:** 2023/2025
- **Venue:** arXiv:2304.13343; DASFAA 2025 (main conference)
- **Link:** https://arxiv.org/abs/2304.13343
- **Tags:** memory-controller, plug-and-play, no-fine-tuning, priority-4

## Core contribution

Three components: an LLM-based agent as the backbone, a memory stream that stores agent memories, and a dedicated **memory controller** that decides when and how to update and retrieve from the memory stream. SCM processes ultra-long inputs without any fine-tuning or model modification, and integrates with any instruction-following LLM in a plug-and-play way. Evaluated on long-term dialogue, book summarization, and meeting summarization, reporting better retrieval recall and more informative responses than competitive baselines. Official code: github.com/wbbeyourself/SCM4LLMs.
