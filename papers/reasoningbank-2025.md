# ReasoningBank: Scaling Agent Self-Evolving with Reasoning Memory

- **Authors:** Siru Ouyang, Jun Yan, I-Hung Hsu, Yanfei Chen, Ke Jiang, Zifeng Wang, et al. (Google Research; 17 authors)
- **Year:** 2025
- **Venue:** arXiv:2509.25140; ICLR 2026
- **Link:** https://arxiv.org/abs/2509.25140
- **Tags:** reasoning-distillation, success-and-failure, matts

## Core contribution

Distills generalizable reasoning strategies (structured as Title/Description/Content items) from the agent's own successful and failed experiences in a retrieve→construct→consolidate loop, plus Memory-aware Test-Time Scaling (MaTTS) that generates diverse/contrastive trajectories to improve memory quality. "Consistently outperforms existing memory mechanisms that store raw trajectories or only successful task routines" (directional, per abstract).

## Relevance to the project

Shows how to learn from both wins and losses — for legal work, losing arguments are as instructive as winning ones.
