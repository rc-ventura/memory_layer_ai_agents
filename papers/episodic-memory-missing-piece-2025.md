# Position: Episodic Memory is the Missing Piece for Long-Term LLM Agents

- **Authors:** Mathis Pink, Qinyuan Wu, Vy Ai Vo, Javier Turek, Jianing Mu, Alexander Huth, Mariya Toneva
- **Year:** 2025
- **Venue:** arXiv:2502.06975
- **Link:** https://arxiv.org/abs/2502.06975
- **Tags:** episodic, position-paper, design-checklist

## Core contribution

Argues episodic memory should be a first-class design target and defines five properties: long-term storage, explicit reasoning, single-shot learning, instance-specific memories, and contextual memories (who/when/where/why).

## Relevance to the project

A principled checklist for what a legal agent's episodic case-log store must support (e.g., binding facts to matter/client/date/outcome).
