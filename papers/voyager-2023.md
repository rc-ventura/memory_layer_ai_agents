# Voyager: An Open-Ended Embodied Agent with Large Language Models

- **Authors:** Guanzhi Wang, Yuqi Xie, Yunfan Jiang, Ajay Mandlekar, Chaowei Xiao, Yuke Zhu, Linxi Fan, Anima Anandkumar
- **Year:** 2023
- **Venue:** arXiv:2305.16291; TMLR 2024
- **Link:** https://arxiv.org/abs/2305.16291
- **Tags:** skill-library, self-verification, catastrophic-forgetting

## Core contribution

An ever-growing skill library of executable code stored in a vector DB and retrieved by similarity, with self-verification before a skill is committed; skills are compositional and mitigate catastrophic forgetting. "Obtains 3.3x more unique items, travels 2.3x longer distances, and unlocks key tech tree milestones up to 15.3x faster than prior SOTA," the only method to unlock the diamond tier (per abstract).

## Relevance to the project

The archetype for "distill experience into reusable, retrievable skills with a verification gate" — directly analogous to converting session history into vetted legal procedures.
