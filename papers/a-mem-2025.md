# A-MEM: Agentic Memory for LLM Agents

- **Authors:** Wujiang Xu, Zujie Liang, Kai Mei, Hang Gao, Juntao Tan, Yongfeng Zhang
- **Year:** 2025
- **Venue:** arXiv:2502.12110; NeurIPS 2025
- **Link:** https://arxiv.org/abs/2502.12110
- **Tags:** zettelkasten, linked-notes, memory-evolution

## Core contribution

Zettelkasten-inspired memory where each memory is a structured note (keywords, context, tags) dynamically linked to others; a "memory evolution" step lets existing notes be retroactively refined/strengthened. Reports "up to a six-fold improvement in ROUGE-L for multi-hop tasks with non-GPT models" while reducing "token usage per memory operation by 85-93% compared to baselines" (LoCoMo, vs. MemGPT/MemoryBank/ReadAgent).

## Relevance to the project

A concrete model for evolving/editing an interconnected knowledge net rather than an append-only log.
