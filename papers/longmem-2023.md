# Augmenting Language Models with Long-Term Memory (LongMem)

- **Authors:** Weizhi Wang, Li Dong, Hao Cheng, Xiaodong Liu, Xifeng Yan, Jianfeng Gao, Furu Wei
- **Year:** 2023
- **Venue:** NeurIPS 2023
- **Tags:** long-term-memory, decoupled-module, cache

## Core contribution

A decoupled long-term memory module that lets an LLM cache and retrieve past context beyond the context window.

## Relevance to the project

Foundational for the "persistent retrieved memory" pattern distinct from the working context.
