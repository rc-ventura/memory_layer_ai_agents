# Memp: Exploring Agent Procedural Memory

- **Authors:** Runnan Fang, Yuan Liang, Xiaobin Wang, Jialong Wu, Shuofei Qiao, Pengjun Xie, Fei Huang, Huajun Chen, Ningyu Zhang (Zhejiang University + Alibaba Group)
- **Year:** 2025
- **Venue:** arXiv:2508.06433; ACL 2026 Findings
- **Link:** https://arxiv.org/abs/2508.06433
- **Tags:** procedural-memory, build-retrieval-update, deprecation, cross-model-transfer

## Core contribution

Treats procedural memory as a learnable, updatable, lifelong object; distills trajectories into fine-grained step-by-step instructions and higher-level script-like abstractions, systematically studying Build/Retrieval/Update strategies with a dynamic regimen that corrects and deprecates memory. On TravelPlanner/ALFWorld, refined memory yields steadily higher success rates, and procedural memory built from a stronger model migrated to a weaker model "can also yield substantial performance gains" (directional).

## Relevance to the project

The most direct academic treatment of "convert session history into reusable procedures," including explicit deprecation — exactly the project's mechanism.
