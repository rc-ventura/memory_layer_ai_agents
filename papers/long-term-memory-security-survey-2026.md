# A Survey on Long-Term Memory Security in LLM Agents: Attacks, Defenses, and Governance Across the Memory Lifecycle

- **Authors:** Zehao Lin, et al. (8 authors)
- **Year:** 2026
- **Venue:** arXiv:2604.16548
- **Link:** https://arxiv.org/abs/2604.16548
- **Tags:** security, memory-poisoning, governance, vmg

## Core contribution

A Memory Lifecycle Framework (six phases: Write, Store, Retrieve, Execute, Share/Propagate, Forget/Rollback × four objectives: Integrity, Confidentiality, Availability, Governance) and Verifiable Memory Governance (VMG) primitives.

## Relevance to the project

Memory-poisoning and governance risk is a first-order concern for a bank's legal AI; frames controls on memory writes.
