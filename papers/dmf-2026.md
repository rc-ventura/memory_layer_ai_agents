# DMF: A Deterministic Memory Framework for Conversational AI Agents

- **Authors:** Matteo Stabile, Enrico Zimuel (Roma Tre University)
- **Year:** 2026
- **Venue:** arXiv:2606.03463
- **Link:** https://arxiv.org/abs/2606.03463
- **Tags:** deterministic, no-llm-calls, survival-score, auditable

## Core contribution

Replaces LLM-based memory summarization with a fully deterministic pipeline — each interaction receives a "Survival Score Ω" computed from content signals, conversational cues, and structured provenance combined via a logistic projection, plus an interaction-count decay law; no LLM calls in the memory-management loop. "DMF achieves comparable accuracy while using zero tokens to prepare the memory context and 5x to 242x fewer tokens over the entire conversation" (vs. Mem0, on LoCoMo/LongMemEval).

## Relevance to the project

The strongest example of a deterministic, signal-driven, auditable update rule — highly attractive for legal settings where every memory change must be explainable and reproducible.
